# doane_portfolio

Tenure portfolio site for Amna Qureshi, Doane University (2024–2027).

**Live site:** https://amnaqureshi1.github.io/doane_portfolio/

## Local development

```sh
npm install
npm run dev
```

Open http://localhost:4321/doane_portfolio/

## Deploy

Pushes to `main` deploy automatically via GitHub Actions.
